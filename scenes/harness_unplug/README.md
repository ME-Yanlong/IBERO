# 带真实线束的卡扣拔出与投放（S4 待成组验收）

运行：`python -m ibero.demo --env harness_unplug --viewer --seed 0`。Enter 新回合，P 暂停，N 单步，B 后退，R 只读回放。结束不关闭窗口。

从 `scene_config.yaml` 可索引到两个材料组件：被动弹性舌片梁，以及原生一维 Flex 轴向边弹簧＋能量一致中心线弯曲力。线束长 0.3 m、外径 4 mm、总质量 9 g，连接同一只 60 g 卡扣插头，不额外叠加旧长端头。永久 connect 只连接线束第一节点与插头尾部，机器人抓持始终靠接触。

任务是实际按压解锁、抓持退出至少 75 mm，再降低 20 mm、开爪投入接料托盘。投放存在真实落差，不宣称精密零落差装配；末态必须有插头实体支承接触、低速度并持续 0.5 s。拔出阶段检查姿态，投放后允许物体在支承面自然倾斜。线尾碰托盘不等于插头放置成功。

seed 0 首次完整成功：14.5 s 仿真，线束峰值张力 0.447 N、线束穿透峰值 0.232 mm，无安全失效。并发其他长测期间墙钟耗时约 1372 s，远未实时。完整默认/变体/反事实仍待验收，材料为示例参数而非真实连接器标定。

长测：`python scripts/verify_latch_robot.py --scene harness_unplug --workers 4`，需冻结源码；该命令只验收本场景，不把另外一个卡扣场景或加工模块算作通过。

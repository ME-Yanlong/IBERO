# IBERO · 工业双臂具身操作平台

项目主页：https://me-yanlong.github.io/IBERO/

本站是研究演示预览，包含 Core 能力介绍、4 级柔性布线、卡扣与连接器拆卸、3 类铣削及基础双臂操作，共 11 段真实仿真录像。

完整仿真器、B3/B4 控制器、场景配置、内部轨迹与训练实现暂未公开，后续将结合论文与项目进展安排发布。仓库既有代码属于历史阶段性版本。

本分支仅用于网站发布，包含网页前端、精选视频与封面、简要演示记录和第三方许可。单条演示不代表多种子成功率或实物材料标定；切屑为视觉效果。

视频、图片、文字与网页设计仅供项目介绍与浏览。除第三方另行许可的部分外，未授予其他用途的许可。第三方模型许可见 THIRD_PARTY_NOTICES.txt。

## 先看效果

完成导出后的本地入口：`artifacts/demo_videos_20260928/index.html`。双击打开，无需启动 Python、MuJoCo 或服务器；也可以直接打开其中的 MP4。

共七段：双臂线束交接、双臂张力控制、弹性卡扣按压拔出、带线束拔出放置、铣削通孔、铣削直槽、铣削浅腔。

每段保留完整动作，以**仿真时间 1×**播放。例如仿真里 10 秒的运动在视频里也是约 10 秒，不必等待慢速物理计算。片头停留 1.52 秒、片尾停留 2 秒，方便认清初始状态与最终结果。网页另提供 0.5×、2×、4×。

视频为 960×752、25 fps、H.264 / yuv420p，无音轨。线束保留四路视角和张力；卡扣、铣削保留全景、局部、俯视与材料/接触面板。铣削俯视隐藏工具**仅作用于显示**，方便看孔槽；实际加工局部仍显示工具。

## 新增文件与复现

没有修改底层仿真器、场景参数、控制策略或用户的 `peng_readme.md`。

- `scripts/export_demo_video.py`：单轨迹离线渲染、时间映射、视频编码、完整解码检查、来源记录。
- `scripts/record_demo_showcase.py`：串行整理这七个具体案例，复用已通过校验的成片，生成本地网页目录。
- `tests/test_video_export.py`：时间采样、加速、边界输入、不同任务成功字段的测试。

编码器来自 PyPI `imageio-ffmpeg==0.6.0` 的 Windows wheel，解压在 `artifacts/video_tools/ffmpeg/`，**未安装到或改动现有 Python 环境**。运行下面命令前应激活原有 `ibero-core` 环境：

```powershell
# 重新检查并整理录像；已有成片及摘要一致时直接复用。
python scripts/record_demo_showcase.py --ffmpeg artifacts/video_tools/ffmpeg/imageio_ffmpeg/binaries/ffmpeg-win-x86_64-v7.1.exe

# 单轨迹导出的可选参数。
python scripts/export_demo_video.py --help

# 仅验证新增加的视频工具，不启动仿真长测。
python -m pytest tests/test_video_export.py -q
```

单轨迹导出支持 `--env`、`--shape`、`--trace`、`--report`、`--output`、`--ffmpeg`、`--fps`、`--speed` 和 `--preview-only`。例如 `--speed 2` 表示两秒仿真运动在一秒视频内播放；`--preview-only` 只生成首中末帧检查图。

**重要：**单轨迹命令必须在与轨迹匹配的源码环境运行；批量脚本已经为每个子进程设置对应冻结目录和 `PYTHONPATH`。不要直接用当前安装版本读取旧轨迹。批量脚本依赖本机保留的历史 worktree/证据，并非从 GitHub 单独克隆源码后就能无条件重建所有历史录像。

## 成片检查与存放

每段同名 `.json` 记录原始轨迹/报告路径与摘要、源码/场景/资产身份、seed、仿真时长、帧率、成功依据、视频摘要、完整解码结果。`.poster.png` 是末帧；`.preview.png` 是首中末三帧。

导出工具会完整解码 MP4，核对帧数并拒绝解码错误，而不是只检查文件存在。生成后仍需人工查看代表帧，确认相机、文字和实际动作可见。

录像、编码器和历史证据放在被 Git 忽略的 `artifacts/`；本次不会把大视频或第三方可执行程序自动提交到 GitHub。独立观看只需复制视频目录，不需要编码器或历史源码。

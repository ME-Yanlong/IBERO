# 场景贡献与离线演示目录

本页说明现有任务目录和视频打包入口。布线场景的物理构建、注册与验证仍以 [Core-0.2 任务书](05_Core-0.2_任务场景与布线开发任务书.md)及实际代码为准；任务目录中出现一个菜谱，只表示文件被发现，不能替代场景校验或机器人成功证据。

## 查看和检查场景

在项目根目录安装开发环境后运行：

```powershell
python -m ibero.task_catalog
python -m ibero.task_catalog --json
python -m ibero.check_scene scenes/cable_stretch
python -m ibero.check_scene scenes/cable_clip_insert
python -m ibero.check_scene scenes/cable_route_straight
python -m ibero.check_scene scenes/cable_route_l
python -m ibero.check_scene scenes/cable_route_rectangle
python -m ibero.check_scene scenes/cable_clip_insert_offset
```

`task_catalog` 扫描 `scenes/` 下的配置，标记任务、参数变体和机制台架，并输出相对于场景根目录的路径与菜谱源码摘要。它只解析 YAML 和 `task_spec.py` 中静态的 `instruction` 类属性或 `TASK_SPEC` 构造参数，不会导入或执行贡献者代码。`--scenes-dir` 可指向另一组场景。

当前四个布线菜谱均可检查、编译和启动。其中单夹与三夹直线已有完整成功回合；L 形与开口矩形仍是**未通过验收的候选任务**，会真实报告失败原因，不能当作成功演示。可运行：

```powershell
python -m ibero.demo --env cable_clip_insert --seed 0
python -m ibero.demo --env cable_route_straight --seed 0 --viewer
python -m ibero.demo --env cable_route_l --seed 0
python -m ibero.demo --env cable_route_rectangle --seed 0
python -m ibero.demo --env cable_clip_insert --scene scenes/cable_clip_insert_offset --seed 0
```

单夹场景从裸线抓取、压入到松手保持；三夹直线场景展示连续布线。`cable_clip_insert_offset` 是仅改菜谱和薄任务说明的贡献样例，线夹横移 6 mm，seed 0 完整回合成功。是否成功以程序输出和任务报告为准，目录列表本身不判定任务完成。

本轮单夹与直线录像已经打包到 `artifacts/core02_showcase/site/index.html`。网页及两段 MP4 的内容有来源 JSON、视频 SHA-256 和全片解码记录；`artifacts/` 默认不入 Git，需要分享时复制或压缩整个 `site` 文件夹。

新场景仍应包含 `scene_config.yaml`、`constraints.yaml`、`task_spec.py` 和简短 README。当前可执行任务依赖已实现的物理组件与注册入口；新增线材、夹具、工艺的物理类型需要新增并验证相应构建器。在已支持的布线组件范围内，改变线夹布局、线材参数或目标路径应优先通过菜谱完成。

任务说明至少要写清楚：真实工作目标、初态、机器人与末端配置、材料参数及其来源、成功条件、超限边界、已知物理近似、查看结果的命令。`task_spec.py` 是受信任的 Python 程序，目录扫描安全并不意味着可以安全执行任意第三方任务脚本。

## 打包可以发给别人的视频网页

新版打包脚本接受**显式清单**，不查找某台机器上的历史 worktree。先准备已导出的 MP4；如果导出时生成了同名 JSON 来源记录，也放在清单旁或引用其相对路径。

若新录像及其来源记录已经放在同一文件夹，可先自动生成清单，再按需编辑标题和描述：

```powershell
python scripts/make_demo_gallery_manifest.py --videos-dir artifacts/my_videos --output artifacts/my_videos/gallery_manifest.json --title "IBERO 布线任务"
```

例如，在 `artifacts/my_videos/gallery_manifest.json` 中写：

```json
{
  "title": "IBERO 任务演示",
  "entries": [
    {
      "id": "cable_clip_insert",
      "title": "双臂将线束压入侧向线夹",
      "description": "松手后线束仍保持在线夹内。",
      "video": "cable_clip_insert.mp4",
      "source_manifest": "cable_clip_insert.json",
      "report": "cable_clip_insert.report.json"
    }
  ]
}
```

这里的文件名只是示例。`source_manifest` 和 `report` 可省略，但页面会显示来源未验证或结果未知，不能冒充经过检查的成功回合。若来源记录声明了视频 SHA-256，脚本会核对实际 MP4；不一致就拒绝制作目录。报告由原任务验证流程产生，打包脚本不重新判定任务是否成功。

```powershell
python scripts/build_demo_gallery.py --manifest artifacts/my_videos/gallery_manifest.json --output-dir artifacts/my_gallery
```

打开 `artifacts/my_gallery/index.html` 即可播放；复制或压缩整个 `my_gallery` 文件夹就能分享。页面可选 0.5×、1×、2×、4×；所有视频和记录均为相对路径。脚本复制文件到新目录，拒绝覆盖已有目录。`index.json` 保存每个视频的摘要和来源状态，方便核对。

网页视频按录像时钟播放，不代表仿真求解达到实时速度。一个成功录像也不等于整套任务的种子矩阵、反例、实测标定或正式版本验收已经通过。

# 工业机制验收数据

`industrial_gates.yaml` 是开始调参前固定的 `C01-IND-GATES-1` 工程门槛。
它不是行业标准，也不是实际材料参数。变化需记录理由和批准依据。

S0 用 `python scripts/industrial_baseline.py` 重建已有场景基线。脚本只调用
现有验收入口，不修改物理；每次创建独立时间戳目录，保留 stdout/stderr、
退出码、场景/源码/资产 hash、环境版本和完整种子结果。

后续每份材料报告至少包含：

- 任务编号、门槛版本、输入参数和来源（示例/解析/数值参考/实测）。
- 运行版本、实际随机量、每个种子及失败原因。
- 每项指标的单位、参考值、实际值、阈值及 pass/fail。
- 原始曲线、运行命令、输出路径、耗时和资源配置。

调参集和留出集分离；独立解析量不得调用被测实现生成参考答案。
原始运行产物存于忽略跟踪的 `artifacts/industrial_core01/`，长期摘要写入
开发文档；具有复用价值的小型参考数据及来源另纳入版本管理。
